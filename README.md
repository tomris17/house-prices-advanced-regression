This repository contains an end-to-end machine learning solution for the **Kaggle House Prices** competition. The goal is to predict the final sales price of residential homes based on dozens of explanatory variables describing physical attributes, location, and amenities.

---

## 📊 Project Overview
* **Objective:** Build an advanced regression model to predict housing prices (evaluated using Root Mean Squared Error - RMSE on log-transformed prices).
* **Key Steps:**
  * Comprehensive Exploratory Data Analysis (EDA) and missing value imputation.
  * Advanced Feature Engineering (handling skewed distributions, creating interaction features, encoding categorical variables).
  * Model Training using powerful regression algorithms (Ridge, Lasso, Random Forest, and Gradient Boosting / XGBoost).
  * Interactive web dashboard deployment via **Streamlit** for real-time price prediction.
